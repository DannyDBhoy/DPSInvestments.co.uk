# Devine Property Solutions

A responsive, five-page static website for a Fife property refurbishment business planning to begin in 2027. Charcoal and gold, with locally hosted assets and no build dependencies.

## Develop

From `/workspace/DPSInvestments.co.uk`:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Pages: `index.html`, `about.html`, `plans.html`, `projects.html`, and `approach.html`. Styles and navigation are in `assets/`.

## Deployment

Serve the repository root on any static hosting service. This draft has not been published or connected to the existing domain.

## Content status

Company name, Fife focus, planned 2027 start, and cash-led business model are based on the owner's brief. No projects, track record, company registration details, contact details, or investment offerings have been invented. Add verified contact details before creating a contact page. The architectural illustration is decorative, not a photograph of a company project.
